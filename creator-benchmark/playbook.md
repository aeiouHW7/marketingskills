# 情侣动物 IP 运营 Playbook

> **来源标记**：【API实测】= RedFox 平台数据可直接采信；【网络检索】= 第三方二手口径，数字需平台内核验。观察日期 2026-10-31。

## Phase 0 内容假设（2026-10-31 修订：情侣故事为核，人格设定为器）

我们相信 18-30 岁年轻女性需要不塌房、可持续追更的情侣故事——真人情侣有塌房风险、纯宠物账号没有剧情。我们用「热情软萌的矮袋鼠女孩 × 高冷毒舌的兔狲男孩」这对反差 CP 赢：物种反差自带喜剧张力，性格反差驱动每一次剧情冲突与和解，动物形象可长期 IP 化。
角色性格（ENFJ/INTJ）只为塑造服务：一个主动表达、一个行动式温柔，构成"追与被追、融化与嘴硬"的戏剧引擎。**不把 MBTI 当账号标签和选题主轴**，仅作彩蛋级元素。
Disqualifiers：不做真人口播；不做素材搬运；不做猎奇科普向；不做"饲养引导"内容（两个物种均为受保护动物，纯虚构 IP 定位最安全）。

## 爆款结构模板（【网络检索】定性拆解 + 【API实测】结构验证）

### 模板 1：反差 CP 单元剧（骨架来自【网络检索】豚咔咔/元宝和丸子 + 【API实测】@sixs/@伤害尾部叙事节奏）
```
钩子(0-3s)：冲突预告字幕/画面（"当INTJ男友发现我偷偷给他报了聚会"）
结构：ENFJ 发起事件 → INTJ 高冷应对 → 反转（INTJ 用行动式温柔收尾）
价值机制：嗑糖 + MBTI 认领（"这就是我对象！"）
CTA：评论区人格测试钩子（"你家那位是i人还是e人？"）
```

### 模板 2：反差性格互动（骨架来自【API实测】噜噜噜妹"不同情侣去旅游的状态"类场景题；MBTI 仅作彩蛋不再作主钩子）
```
钩子："测测你是恋爱中的哪种动物塑"
结构：4-6 格/分镜，不同人格动物在同一个恋爱场景的不同反应
价值机制：身份认同 + 转发到情侣群/闺蜜群
复用性：极高，一个场景 × 16 型人格 = 16 条内容
```

### 模板 3：表情包冷启动（【网络检索】负鼠案例 + 【API实测】噜噜表情包二创 5-6万转发验证）
```
每周固定产出 1 组 9 宫格表情包（恋爱场景 + 情绪文案）
投放：微信表情商店 + 小红书"表情包"话题
目的：不涨粉也涨"传播资产"，是小黄豚验证过的低冷启动路径
```

### 模板 4：专属 BGM 洗脑（骨架来自狲思邈《赤実》）
```
为 IP 定制/选定一段专属短旋律，所有视频统一使用。
兔狲镜头出现 = BGM 前奏先出，形成条件反射式记忆点。
```

## 差异化地图

| 维度 | 对标做法 | 我们刻意不同 | 我们的 edge |
|---|---|---|---|
| 形象 | 真实宠物 / 泛拟人卡通 | 真实物种+真实外貌特征（兔狲圆脸不屑眼、矮袋鼠永远微笑） | 物种自带梗，无需教育 |
| 人设 | 猫狗CP | MBTI 16 型人格挂钩，人设可体系化（后续可扩配角矩阵如喵小兔） | 每条内容自带 MBTI 互动钩子 |
| 叙事 | 日常记录 | 连续剧感：认识→追→确认关系→同居，观众"追进度" | 留存更强 |
| 冷启动 | 内容赌爆款 | 表情包先行铺传播资产 | 起号期不依赖单条运气 |
| 变现 | 带货宠物用品 | 情侣/女性向：文创、礼盒、周边、美妆植入（喵小兔已验证的品类清单） | 避开宠物红海，毛利更高 |

## 变现路线图（【网络检索】二手口径，报价/销售额需核验）

1. **0-1万粉**：小红书商单门槛 1000 粉即可接；AI/动画类报价参考 4500元/条（川岛小猪口径）
2. **1-20万粉**：美妆/食品/文创植入（女性粉占比高的账号品牌偏好此类）
3. **20万粉+**：微信表情包上架（免费但铺心智）→ 盲盒/毛绒周边（小黄豚单品销量数百万级）
4. **头部**：IP 授权联名（喵小兔「IP授权+达人传播」双轨；卡皮巴拉近百家品牌联名）
