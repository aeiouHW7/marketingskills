# Topic Expansion: Diverge Then Deepen (发散与细挖)

Most searches fail because the input is a vague category ("fitness", "AI", "home organization"). This file turns a category into specific angles with proven search demand, then into concrete content ideas.

## Breadth: the Four Lenses

For each lens, write 5–10 answers before judging any of them. Volume first, selection later.

### 1. 人群 (Who)

Split the audience along axes that change the content:

- **Identity**: student, new grad, manager, freelancer, founder, parent, caregiver, retiree
- **Stage**: beginner, struggling, nearly there, advanced, burned out
- **Situation**: renting, first home, new city, new job, post-breakup, new baby
- **Resources**: budget, time-poor, no equipment, no permission, small space
- **Belief**: skeptic, enthusiast, returning after failure, professionally required

Prompts:

- Who is the most specific person who would save this post?
- Who would share it to look smart?
- Who has tried the common advice and failed?
- Whose version of this problem is invisible to big creators?

### 2. 场景 (When/Where)

- **Time**: morning, lunch break, late night, weekend, Monday reset, month-end
- **Season/event**: spring cleaning, back-to-school, holidays, Chinese New Year, tax season, summer body
- **Trigger**: moving, job change, breakup, new baby, first paycheck, price increase
- **Place**: apartment, office desk, kitchen, gym, commute, hotel, travel
- **Constraint**: 5 minutes, ¥100, no tools, shared space, no sunlight

Prompts:

- When does this problem become urgent?
- What event makes someone search for this today?
- Where does the workaround physically happen?

### 3. 问题 (Why/Pain)

- **Pain**: time cost, money cost, embarrassment, decision fatigue, repeated failure
- **Myth**: common advice that does not work in this situation
- **Failure story**: "I tried X and it broke"
- **Hidden cost**: maintenance, storage, subscriptions, mental load
- **Objection**: "this is too expensive / too hard / not for me"
- **Trade-off**: speed vs. quality, cheap vs. durable, simple vs. complete

Prompts:

- What do people complain about in the comments of the top posts?
- What does the audience believe that is wrong or incomplete?
- What is the embarrassing part they will not say out loud?

### 4. 结果 (What/Outcome)

- **Functional**: save 3 hours, cut cost 40%, finish in one weekend
- **Emotional**: feel calm, feel in control, feel proud
- **Identity**: "I'm the kind of person who..."
- **Social**: looks good to roommates, partner, boss, followers
- **Before/after**: messy → tidy, novice → competent, chaotic → systemized

Prompts:

- What does the viewer want to be true after watching?
- What would they screenshot and send to a friend?
- What transformation is believable for this creator?

## Depth: the Five Drills

Take the strongest 10 angles. Drill each one level deeper. A drilled angle is more searchable and more original.

### Drill 1 — 词 (keyword ladder)

Turn a category into how real people phrase the problem.

| Rung | Pattern | Example (career niche) |
|------|---------|------------------------|
| Core | category | 职场 |
| Modified | category + constraint | 职场新人 |
| Question | how/what/why | 职场新人怎么快速上手 |
| Colloquial | spoken phrasing | 刚入职啥也不会怎么办 |
| Emotional | feeling + situation | 刚入职天天怕被开除 |

Generate at least three colloquial and one emotional rung per pillar.

### Drill 2 — 人 (specificity)

Everyone → a segment → one person's day.

```
所有人 → 刚转行的设计师 → 一个转行三个月、每天加班到十点、还在用旧作品集接单的设计师
```

Specificity creates recognition ("that's me") and gives the content a concrete scene.

### Drill 3 — 事 (incident)

Opinion → scene → conflict → reversal.

```
观点: 早起很重要
场景: 我连续早起 30 天
冲突: 前两周效率更高，第三周开始崩溃
反转: 问题不在早起，在于睡前刷手机
```

### Drill 4 — 证 (evidence)

Claim → proof. Weak content asserts; strong content shows.

- A number ("I tracked this for 30 days")
- A comparison ("same task with and without this method")
- A before/after ("here is the actual screen / room / result")
- A first-hand test ("I bought the 3 cheapest options")
- A named source or expert quote

### Drill 5 — 反 (contrarian)

Consensus → opposite → boundary condition.

```
共识: 收纳要靠收纳盒
反向: 收纳盒越多越乱
边界: 只有在你有固定归位习惯时，收纳盒才有效
```

Always include the boundary condition. Pure contrarianism without nuance reads as engagement bait and damages trust.

## The Keyword Ladder

Run this for each pillar. The output is the raw material for Phase 2.

```
Core category
├── + audience        (新人 / 宝妈 / 租房党 / 程序员)
├── + scene           (搬家 / 开学 / 通勤 / 睡前)
├── + problem         (太乱 / 没时间 / 不会选 / 总失败)
├── + outcome         (一周见效 / 100 元以内 / 不用断舍离)
├── + question form   (怎么 / 为什么 / 值不值 / 哪个好)
├── + colloquial      (到底 / 真的 / 有没有 / 求推荐)
└── + emotion         (崩溃 / 焦虑 / 后悔 / 真香)
```

Combine two rungs at most. Three-rung phrases are usually too narrow to have volume.

## From Angle to Query

An angle is not a query until it is phrased the way the platform's search box expects it.

| Angle | Douyin query | Xiaohongshu query | X query | TikTok query |
|-------|--------------|-------------------|---------|--------------|
| Small-apartment storage for renters | 出租屋收纳 | 出租屋收纳 小户型 | "small apartment" storage renter | small apartment storage |
| Beginner AI-agent workflow | AI智能体 入门 | AI agent 新手 教程 | "AI agent" min_faves:500 | ai agent tutorial |
| Home coffee for beginners | 新手 手冲咖啡 | 手冲咖啡 入门 平价 | "pour over" beginner | pour over coffee beginner |

For each angle, produce one query per selected platform. Do not reuse the same string everywhere.

## Prioritization

Score each query 1–5 on three dimensions:

```
priority = demand × fit × feasibility
```

- **Demand**: suggestion terms exist, top posts have strong engagement, multiple creators cover it
- **Fit**: matches the content hypothesis and the user's credibility
- **Feasibility**: can be produced with the user's face/voice/budget/time

Keep the top 30–50. Kill queries that are:
- Already saturated by mega-accounts with no long-tail opening
- Outside the user's credible experience
- Impossible to prove or demonstrate
- Seasonal but outside the next 90 days

## Worked Examples

### Example 1 — Home organization (小红书)

```
Pillar: 出租屋收纳
Lens 人群: 租房党 / 刚毕业 / 小户型 / 情侣合租 / 养猫
Lens 场景: 搬家后一周 / 春节前 / 换季 / 房东不给打孔
Lens 问题: 收纳盒买越多越乱 / 不敢扔东西 / 下班没力气收拾
Lens 结果: 10 平米看起来像 20 平米 / 找东西不超过 10 秒

Drill 词: 出租屋收纳 → 出租屋收纳 不打孔 → 出租屋怎么收纳才不显乱 → 房东不让打孔怎么收纳
Drill 事: 我搬家三次才明白，收纳盒不是越多越好
Drill 证: 同样的 10 平米，改造前后对比 + 花费清单
Drill 反: 断舍离不适合租房党，先做"可带走的收纳"

Output queries:
- 出租屋收纳 不打孔
- 小户型 收纳 前后对比
- 租房 收纳 平价
- 收纳盒 越多越乱
- 搬家 收纳 清单
```

### Example 2 — B2B SaaS (X)

```
Pillar: AI agents for ops teams
Lens 人群: ops lead / solo founder / agency owner / non-technical PM
Lens 场景: manual reporting / new hire onboarding / month-end close
Lens 问题: brittle Zapier chains / no audit trail / hallucinated outputs
Lens 结果: save 10 hours/week / one reliable workflow / fewer errors

Drill 词: AI agent → AI agent for ops → how to audit an AI agent → our agent broke in production
Drill 证: before/after workflow diagram + failure logs
Drill 反: most AI agent demos are theater; here is the boring reliability layer

Output queries:
- "AI agent" ops min_faves:300
- "AI agent" production filter:media
- "Zapier" brittle min_faves:100
- "agent" audit lang:en
```

### Example 3 — Fitness (TikTok)

```
Pillar: beginner strength training at home
Lens 人群: complete beginner / no equipment / busy parent / returning after injury
Lens 场景: 15-minute lunch break / after kids sleep / hotel room
Lens 问题: no time / fear of bad form / program hopping
Lens 结果: first pull-up / stronger back / consistent 3x/week

Drill 词: home workout → beginner home workout no equipment → 15 minute beginner workout → workout when you hate working out
Drill 事: I trained 15 minutes a day for 30 days
Drill 证: same lift before/after + weekly schedule screenshot
Drill 反: you do not need motivation; you need a smaller minimum

Output queries:
- beginner home workout no equipment
- 15 minute workout busy parent
- first pull up progression
- workout consistency minimum
```

## Checklist

- [ ] 3–5 content pillars defined
- [ ] At least 5 angles per lens
- [ ] Top 10 angles drilled through at least two drills
- [ ] Keyword ladder built for each pillar
- [ ] 30–50 queries, deduplicated per platform
- [ ] Prioritized by demand × fit × feasibility
- [ ] Each query traces back to a specific audience and angle
- [ ] No query depends on a claim the user cannot prove
