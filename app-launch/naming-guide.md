# App 起名指南 · 情侣/好友打卡 PK

> 核心认知：你想用的词大概率被占了。好消息是——正因为品类词全被占，**独创合成词反而是最优解**（可注册商标、可拿域名、TikTok handle 可申请）。

---

## 一、从哪些维度思考（6 个起名方向）

### 方向 1：双人机制的隐喻（你的产品差异点）
想想"两个人绑在一起做事"的意象：双人自行车、接力、拴绳、跷跷板、tag team、双打。
- 可用词根：duo / pair / tandem / relay / tag / two / sync / echo / mirror
- ⚠️ 避雷：Duo（Duolingo+Duo 安全应用双重占用）、Tandem（语言交换 App）、Pair/Paired（已占）、Duet（Duet Display 已占）

### 方向 2：赌约/比拼的隐喻（你的 PK 玩法）
- 可用词根：bet / stake / wager / ante / forfeit / challenge / duel / versus / race
- ⚠️ 避雷：Forfeit（已占）、Pact（曾经的习惯赌约 App，商标状态要查）、Stakes（金融联想）

### 方向 3：连胜/积累的隐喻
- 可用词根：streak / chain / spark / ember / kindle / stack
- ⚠️ 避雷：Streaks（已占）、Flame/Flamme（已占）、Kindle（亚马逊）
- 好苗子：ember/spark 系（火星苗=连胜的火别灭），语义和"连胜不断"高度契合

### 方向 4：独创合成词（★ 最推荐）
拍两个词根拼一个新词，像 HabitKit、Waffle 这类"好读的生造词"。好处：商标能注册、域名能买到、社媒 handle 干净、搜索时不会被大词淹没。
- 拼法示例（仅示范思路，均需过检查流程）：Habit 末端拼：Habitual→Habito（有占）/ Habbr / Hivemind 类；Streak 系：Streakly / Streeko；双人系：Twyn / Dupple / Palokeep

### 方向 5：ASO 后缀策略（名字和搜索词分开解决）
App Store 的 App Name 有 30 字符，可以"品牌词 + 场景词"组合：**`Brandname — Couples Habit Challenge`**。所以名字本身不必背负 SEO 任务，把 "couples/challenge/streak" 塞进后缀即可。**这条大大放宽了起名自由度**——名字只需要好记好传播。

### 方向 6：声音与传播测试（TikTok 时代的硬要求）
你的名字会被主播在视频里喊出来：
- **电话测试**：念一遍，陌生人能正确拼出来吗？（拼不出来的名字会流失搜索流量）
- **口播测试**：`Download XX, it's free` 这句里 XX 顺不顺口？
- 一或两个音节最好，重音清晰，别有英语里容易连读吞音的结构

## 二、查重漏斗（按顺序过，任何一关不过就弃）

| 层 | 查什么 | 工具 | 不过的后果 |
|----|--------|------|-----------|
| ① 商店重名 | App Store + Google Play 搜精确名 | 直接搜 | 苹果要求 App Name 唯一，重名直接不能用 |
| ② 商标 | 美国 USPTO（TMEP/TESS 检索，免费）、英国 UKIPO、WIPO Global Brand DB；**查 Class 9（软件）和 Class 42（SaaS）** | tmsearch.uspto.gov | 最贵的一关。侵权会被下架甚至被诉；目标市场是美加澳英，至少查美国+英国 |
| ③ 域名 | .com 和 .app（.app 是 Google 运营的 TLD，天然适合 App） | Namecheap / Porkbun | 拿不到 .com 至少要能拿 .app 或 getxxx.com |
| ④ 社媒 handle | TikTok / Instagram / X | namechk.com、instantusername.com | 你的增长引擎是 TikTok——handle 被占等于作战地图没有主阵地 |
| ⑤ 语义撞车 | Google 搜 "名字 + app"、Urban Dictionary 查俚语、主要语言负面含义 | 搜索引擎 | 上线后才发现名字在某语言里是脏话 = 返厂重造 |

**顺序很重要**：先过①（最快最免费），最后才纠结域名。很多人反过来，先买域名再发现商标冲突，白花钱。

## 三、命名判分卡（候选名过完漏斗后打分）

| 维度 | 满分 | 打分要点 |
|------|------|----------|
| 可读可拼 | /20 | 电话测试通过、无歧义拼写 |
| 契合机制 | /20 | 听到名字能猜到"两个人比拼打卡"至少一半意思 |
| 可商标 | /20 | 独创度越高分越高（品类通用词直接 0 分） |
| 传播性 | /20 | TikTok 口播顺口、handle 干净、容易被做梗 |
| 成长空间 | /20 | 以后加好友群战/赛季/纪念册不违和；别起太窄（如只暗示情侣，未来想扩好友市场就锁死了——全局版方案里"好友"是半边用户） |

**一条重要提醒**：你的用户有一半是"朋友间比拼"，名字如果起得太情侣（如 Love 系），等于主动放弃另一半市场并锁死 ASO 词。中性的"双人竞速"意象 > 恋爱意象。

---

## 四、行动清单

1. 按方向 1-4 各头脑风暴 10 个词根组合（30 分钟），产出 20-40 个候选
2. 全部过查重漏斗①②（半天），预计淘汰 70%+——正常，所以才要海选
3. 剩余候选打分卡排序，取前 3
4. 前 3 名做最终验证：域名+handle 一把查、让 5 个母语者念并复述拼写
5. 定名后 48 小时内：注册 TikTok/IG handle、买域名、提交商标申请（TM 基础申请可先占位，美国申请费约 $350/类）

**⚠️ 定名后最急的一件事是商标**：你的 GA 窗口是 12 月中，商标申请拖到上线后，万一撞到别人在审的商标，改名成本（ASO 排名、评分、账号、素材）比现在多十倍。
